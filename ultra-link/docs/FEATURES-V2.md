# ألترا لينك — الإصدار الثاني: الموقع، المتاجر، الروابط، والتواصل

> وثيقة تصميم قبل البناء. ما هو **قرار** مكتوب كقرار، وما هو **فرضية** مكتوب كفرضية. لا شيء هنا يفعّل مدفوعات.

## 0. الطلبات كما فهمتها
1. **الموقع والأقرب**: شخص يقول «عندي سيارة بمكان كذا» ويشارك موقعه (ويُتابَع موقع سيارته مباشرة ما دام يختار المشاركة)، وآخر يقول «بدي سيارة بمكان كذا تبعد عني كذا كم» فيظهر له **الأقرب أولًا** ضمن المسافة.
2. **المتجر والكتالوج**: صاحب محل يضع محله كله: قائمة منتجات بأسعارها (وصور لاحقًا)، وكل منتج قابل للمطابقة.
3. **الروابط**: رابط قابل للمشاركة لمنتج، أو لمكان، أو لمتجر كامل، أو **رابط يجمع عدة روابط**، بمدة صلاحية واضحة.
4. **طريقة التواصل**: كيف يتواصل الطرفان بعد المطابقة، متى يظهر «الربط» بينهما، وإلى متى يبقى.

## 1. الموقع الدقيق والأقرب (Rides / nearby)

### 1.1 مستويات الدقة
| المستوى | المصدر | يُخزَّن | يُعرض للآخرين قبل التواصل |
|---|---|---|---|
| مكان مسمّى | الكلام («بإعزاز») | `point_place_id` (الحالي) | اسم المكان |
| نقطة GPS | زر «استخدم موقعي» (إذن المتصفح) | lat/lng + الدقة بالمتر | **المسافة التقريبية فقط** («≈ ١٫٥ كم») + اسم المنطقة |
| موقع مباشر | مفتاح «شارك موقعي المباشر» لمقدّم الخدمة (سيارة/سائق) | جدول ساخن منفصل يُحدَّث | المسافة التقريبية + «متصل الآن/قبل ٣ د» |

**حقيقة تقنية:** تطبيق الويب يتابع الموقع **فقط أثناء فتح الصفحة** (`watchPosition`). المتابعة في الخلفية وإغلاق الشاشة تحتاج تطبيقًا أصليًا (Android/iOS) — خطوة لاحقة. نعرض ذلك للسائق بوضوح.

### 1.2 القواعد
- الإحداثيات الدقيقة **لا تُرسل أبدًا** لطرف آخر قبل قبول التواصل؛ بعد القبول يمكن لكل طرف مشاركة موقعه المباشر **لمدة محددة** (١٥/٣٠/٦٠ دقيقة) قابلة للإيقاف.
- تحديثات الموقع المباشر: كل ≥ ١٥ ثانية أو ≥ ٥٠ مترًا؛ الموقع الذي لم يُحدَّث ١٠ دقائق = «غير متصل» ولا يُقدَّم كمطابقة مؤكدة.
- «ضمن 5 كم» / «ما يبعد أكتر من 3 كيلو» = **شرط ملزم** على المسافة؛ «قريب مني» / «الأقرب» = ترتيب بالمسافة (تفضيل) مع حد افتراضي معلن (10 كم للتوصيلات) يمكن للمستخدم تغييره — **لا توسيع تلقائي**.
- تصنيف جديد: `transport.ride` (توصيلة/سيارة مع سائق/تكسي) و`transport.delivery` (توصيل أغراض).

### 1.3 البيانات والفهرسة
- امتداد PostgreSQL `earthdistance` (+`cube`): فهرس GiST على `ll_to_earth(lat, lng)` يدعم **أقرب K** (`ORDER BY … <-> …`) و**ضمن نصف قطر** (`earth_box`) دون مسح كامل.
- `intents`: أعمدة `geo_lat/geo_lng/geo_accuracy_m/geo_source` (نقطة ثابتة).
- `live_positions` (جدول ساخن صغير): صف لكل مستخدم/نية مشارِكة، upsert بلا رفع نسخة النية (لا إعادة مطابقة مع كل نبضة GPS — كلفة).
- المطابقة للفئات «القريبة»: **عند الطلب** (KNN) بدل حفظ كل الأزواج، مع تخزين أفضل K لمدة قصيرة؛ عند طلب توصيلة جديد يُنبَّه **أقرب K سائقين متصلين** فقط (تنبيه بلا تكرار).
- التوسع: تقسيم الموقع المباشر بخلايا geohash/H3 عند الحاجة (خطة، غير مُقاسة).

## 2. المتاجر والكتالوج والصور
- **المتجر** = ملف مقدّم: اسم، مكان/نقطة، وصف، تفضيلات التواصل. **المنتج** = عرض بيع (نية `provide`) مرتبط بالمتجر → يستفيد من كل محرك المطابقة الحالي بلا استثناء.
- **إضافة جماعية**: لصق قائمة أسطر («ايفون 12 مستعمل - 300$»، «شاحن سامسونج ١٠ دولار») → المحلّل يفهم كل سطر (صنف، سعر، عملة، صفات) → **معاينة** يؤكدها صاحب المحل قبل الحفظ → حفظ دفعة واحدة مع تحقق خادمي.
- **الصور**: حتى ٦ صور/منتج، ≤ ٥ ميغابايت، JPEG/PNG/WebP؛ **تُزال بيانات EXIF/GPS** (خصوصية) قبل الحفظ؛ تخزين بعنوان المحتوى (sha256) يمنع التكرار؛ تُعرض فقط إن كان المنتج مرئيًا.
- تعديل السعر = نسخة جديدة → إعادة مطابقة → إبطال المطابقات التي لم تعد صحيحة (نفس الضمانات الحالية).
- النتائج تُجمَّع بالمتجر: «٣ منتجات من متجر أبو أحمد (تجريبي)».

## 3. الروابط (روابط قابلة للمشاركة)
| النوع | المحتوى |
|---|---|
| عرض/طلب | نية واحدة |
| منتج | منتج من متجر |
| متجر | كل منتجات المتجر المتاحة |
| مكان | مكان مسمّى أو نقطة تقريبية + وصف |
| **مجموعة** | قائمة مرتبة من أي مما سبق **أو روابط أخرى** (عمق أقصى ٢، ٥٠ عنصرًا، يمنع الحلقات) |

- **متى يظهر**: ينشئه صاحبه من أي بطاقة («مشاركة») أو بعد مطابقة («أرسل رابط متجري»).
- **إلى متى**: يختار المالك ٢٤ ساعة / ٧ أيام / ٣٠ يومًا / حتى أوقفه. العنصر الذي أُغلق أو انتهى يظهر «غير متاح» تلقائيًا؛ الرابط الذي كل عناصره غير متاحة ٧ أيام ينتهي تلقائيًا؛ الإيقاف اليدوي فوري (صفحة «انتهى هذا الرابط»).
- **الخصوصية**: الرابط عشوائي غير قابل للتخمين (١٢ حرفًا)؛ «غير مدرج» افتراضيًا (يراه من يملك الرابط فقط)؛ لا يكشف الهاتف ولا الموقع الدقيق؛ عدّاد مشاهدات للمالك بلا هوية الزائرين.
- **من يفتح الرابط** يرى المحتوى دون تسجيل؛ للتواصل يسجّل الدخول → طلب تواصل للمالك (نفس مسار الموافقة).

## 4. التواصل — دورة حياة «الربط» بين طرفين
```
مطابقة (مجهولة الهوية) ──▶ طلب تواصل (+رسالة قصيرة اختيارية)
        ▲                          │ الطرف الآخر يرى: الاسم المعروض + ما يريده
   رابط مشاركة                     ▼
                              قبول ──▶ «ربط» مفتوح: محادثة داخل التطبيق
                                         • مشاركة الهاتف بضغطة (اختيارية، لكل طرف)
                                         • مشاركة الموقع المباشر لمدة محددة (للتوصيلات)
                                         • إغلاق / حظر / إبلاغ في أي وقت
                                         ▼
                 أرشفة تلقائية: بعد ١٤ يومًا من إغلاق الطلبين، أو ٣٠ يومًا بلا رسائل
```
- لا يظهر أي رقم هاتف أو موقع دقيق تلقائيًا — كل كشف بقرار صريح من صاحبه.
- الحظر يمنع طلبات التواصل المستقبلية من نفس الشخص.
- التنبيهات: طلب جديد، قبول، رسائل جديدة (مجمّعة)، بدء/انتهاء مشاركة الموقع.

## 6. فرضيات منتج (غير مُثبتة)
- التوصيلات القريبة قد تكون أعلى قيمة يومية في المناطق ذات النقل العام الضعيف — تحتاج قياسًا بعد إطلاق تجريبي.
- أصحاب المحلات سيضيفون منتجاتهم إن كانت الإضافة الجماعية أسرع من ٥ دقائق لـ ٥٠ منتجًا.
- نماذج إيراد محتملة (غير مفعّلة): اشتراك متجر مميز، إبراز إعلان مدفوع، عمولة توصيل — لا تُفعَّل دون تفويض.
