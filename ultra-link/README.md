# ألترا لينك — Ultra Link

يفهم ما يحتاجه الناس وما يستطيعون تقديمه — بالكلام أو بالكتابة — ثم يربط الأطراف المناسبة: بيع وشراء وإيجار، خدمات ومساعدة، دروس، وأنشطة مشتركة (رحلات، رياضة…).

> اضغط الميكروفون وقل: «بدي شقة للإيجار بإعزاز فقط حد أقصى 200 دولار بالشهر، يفضّل طابق أول» — يسأل سؤالًا واحدًا فقط عند نقص معلومة ضرورية، يحفظ الطلب، يبحث فورًا، ويعرض المطابقات مع **أسباب** توافقها، أو يؤكد: «تم حفظ طلبك، سنخبرك عند ظهور مطابقات مناسبة».

## التشغيل محليًا

المتطلبات: Node ≥ 22.18، PostgreSQL 16 (الملفات التنفيذية في `/usr/lib/postgresql/16/bin`)، Chromium لاختبارات المتصفح (اختياري).

```bash
cd ultra-link
npm install                 # مرة واحدة
npm start                   # يشغّل PostgreSQL مخصصًا + الترحيلات + البيانات المرجعية/التجريبية (أول مرة) + الخادم + العامل
# → http://127.0.0.1:8080
npm run status              # حالة قاعدة البيانات والخادم والعامل + /api/health
npm run restart             # إعادة تشغيل الخادم والعامل
npm stop                    # إيقاف الخادم والعامل (PostgreSQL يبقى)
bash scripts/app.sh stop --all   # إيقاف كل شيء بما فيه PostgreSQL
tail -f var/log/server.log var/log/worker.log
```

- قاعدة البيانات **مستقلة** في `ultra-link/var/pgdata` على المنفذ 5544؛ لا تلمس أي عنقود PostgreSQL موجود.
- الأسرار في `ultra-link/.env` (مستثنى من git): `TYPESAFE_API_KEY` وروابط قاعدة البيانات (كلمة المرور تُولَّد محليًا).
- البيانات التجريبية **اصطناعية ومعلّمة** (`realm=synthetic`، كل عنوان ينتهي بـ «(تجريبي)») ولا تُطابَق أبدًا مع حسابات حقيقية.

## سيناريوهات جاهزة للتجربة

ادخل من الشاشة الأولى بإحدى الشخصيات التجريبية:

| # | ما يُثبته | الخطوات | المتوقع |
|---|---|---|---|
| 1 | مطابقة فورية + شرط ملزم + تفضيل | **سامر**: «بدي شقة للإيجار بإعزاز فقط حد أقصى 200 دولار بالشهر، يفضّل طابق أول» | مطابقتان مؤكدتان (180$ طابق أول في الأعلى، 150$)، ٤ محتملة (عملة مختلفة، إيجار سنوي، سعر غير معلن، «للعائلات فقط»)، و«استُبعد: ٢ خارج المكان الذي اشترطته، ١ أعلى من حد السعر» |
| 2 | طلب محفوظ تصله مطابقة لاحقًا | **هدى**: «بدي موتور للبيع بعفرين» (أجب «شراء» إن سُئلت) → «تم حفظ طلبك…» → تبويبة **طلباتي** → «محاكاة: وصول عرض مطابق لاحقًا» | خلال ثوانٍ: العامل في الخلفية يطابق، يصل تنبيه مباشر (SSE) وتزيد شارة التنبيهات |
| 3 | استبعاد بشرط ملزم | السيناريو 1 نفسه، أو «بدي شقة للإيجار بعفرين بالضبط 120 دولار بالشهر» | ملخص الاستبعاد بالسبب، واقتراح توسيع **لا يُطبَّق تلقائيًا** |
| 4 | استيضاح يُجاب عنه مرة واحدة | **رامي**: «بدي شخص يصلّح الغسالة» → يسأل «وين بدك الخدمة؟» (ويُنطق) → «بإعزاز» | لا يُكرر السؤال؛ مطابقة مع فني غسالات وبرادات في إعزاز |
| 5 | تعديل يُبطل مطابقة قديمة | بعد السيناريو 1: **طلباتي** → تعديل → اخفض الحد إلى 160 | مطابقة 180$ تصبح «لم تعد مطابقة» مع السبب «السعر 180$ بالشهر أعلى من حدك (160$)» |
| 6 | تصفح أكثر من 100 نتيجة | **هدى**: «بدي سيارة بحلب» → «شراء» → **المطابقات** | 250 نتيجة، صفحات حقيقية «١٢١–١٤٠ من ٢٥٠» بلا فقدان أو تكرار |

أمثلة أخرى: «عندي سيارة للبيع» (يسأل المكان ثم السعر)، «بدي أطلع رحلة يوم الجمعة» (يسأل المدينة)، «أنا مدرس وبعطي دروس فيزياء بإعزاز» (مطابقة فورية مع طالب بكالوريا تجريبي)، «لا قصدي عفرين» يصحّح بلا سؤال، و«عفرين» بعد «إعزاز» بلا كلمة تصحيح ⇒ سؤال عن التعارض فقط.

## ما بُني

- **فهم الكلام العربي**: محلّل حتمي (لهجة شامية + فصحى) للدور، التصنيف، نوع الصفقة، الأماكن مع الصرامة والنفي، المبالغ بالكلمات والأرقام العربية/الهندية بدقة BigInt، العملة والوحدة، المواعيد بتوقيت سوريا، والصفات/الشروط (ملزم/تفضيل).
- **محادثة**: سؤال واحد في كل مرة، دمج الإجابة في نفس الطلب، عدم تكرار سؤال أُجيب عنه، سؤال التعارض المحدد فقط، حفظ المسودة بعد كل دور (تعود بعد إعادة التحميل)، أدوار idempotent.
- **الصوت**: Web Speech API (تعرّف + نطق) مع كشف الدعم، معالجة رفض الإذن/انقطاع الشبكة/عدم التقاط الكلام، عرض النص أثناء التعرف، إرسال تلقائي بعد مهلة قابلة للإيقاف/التعديل، نطق السؤال ثم الاستماع (half-duplex: لا يسجّل صوت التطبيق)، ونسخة منطوقة مشكّلة **بنفس الحروف** (مختبَر).
- **Jev (TypeSafe)**: عميل وفق عقد SDK الرسمي، يختار بين خيارات فقط، بعتبات ثقة وميزانية زمنية ورجوع للمحلّل المحلي. انظر «حالة Jev».
- **قاعدة البيانات**: انظر docs/ARCHITECTURE.md و docs/DATABASE.md — جدول نيّات موحّد مقسّم بالقطاع، «مفاتيح ربط هرمية» (مجالات أماكن + فهرس نطاقات عكسي) لبحث بلا مسح كامل، مطابقات بنسخ وتسلسل تقييم يمنع الكتابة القديمة، تنبيهات بلا تكرار، طابور مهام، نسخ احتياطي واختبار استعادة.
- **المطابقة**: الشروط الملزمة أولًا ثم ترتيب التفضيلات، المجهول ⇒ «محتملة» لا «مؤكدة»، لا مقارنة لعملات/وحدات مختلفة، لا توسيع تلقائي، إعادة تقييم عند التعديل/الإيقاف/الإغلاق/الانتهاء.
- **الواجهة**: RTL داكنة، ميكروفون مميز، حركات مرتبطة بالحالة (نبض عند الاستماع، مدار عند التحليل، رادار عند البحث)، احترام تقليل الحركة، لوحة المفاتيح، الهاتف؛ تبويبات بعدّادات حية؛ صفحات حقيقية؛ تعديل/إيقاف/إغلاق الطلب؛ طلب تواصل بموافقة الطرفين.

## حالة Jev — بصراحة

- **المفتاح**: موجود في `.env` على الخادم فقط (لا يصل للمتصفح ولا للسجلات ولا لـ git).
- **الاتصال الفعلي: غير مُتحقَّق.** سياسة الشبكة في بيئة التطوير هذه تمنع `api.typesafe.ai` (رفض CONNECT ‏403). لذلك يعمل التطبيق بالمحلّل المحلي، وتعرض الواجهة: «مفتاح Jev موجود — لم يُختبر الاتصال بعد / فشل الاتصال».
- **للتفعيل**: اسمح بالنطاق `api.typesafe.ai` في إعدادات الشبكة للبيئة (قائمة البيئة → Edit → Network access → Allowed domains)، ثم `npm run ai:probe` — فقط `RESULT: VERIFIED` يعني اتصالًا فعليًا.
- **وضع المحاكاة** (معلَّم بوضوح «محاكاة Jev — ليست اتصالًا فعليًا»): `npm run jev:mock` ثم شغّل الخادم بـ `JEV_MODE=simulate TYPESAFE_BASE_URL=http://127.0.0.1:8787`.

## الاختبارات

```bash
npm run test:unit                      # وحدات: المحلّل، المحادثة، الأسئلة المنطوقة، Jev (مع خادم وهمي)، الصوت والآلة (محاكاة)، المطابقة
npm run test:integration               # قواعد معزولة لكل ملف: المطابقة، المهام، الخادم، التدفقات
npm run test:e2e                       # متصفح Chromium على سطح المكتب والهاتف — السيناريوهات الستة
node scripts/corpus-report.ts --fails 10   # دقة الفهم على المدوّنة الموسومة (انظر docs/IMPROVEMENT-LOG.md)
npm run db:backup && npm run db:restore-test
```

> اختبارات الصوت **محاكاة** (واجهة Web Speech وهمية داخل Chromium) — تثبت التوصيل والتوقيت وعدم التداخل، لكنها **ليست** تجربة صوت إنسان حقيقي. قائمة الفحص اليدوي بميكروفون حقيقي في `public/js/conversation/README.md` §7.
